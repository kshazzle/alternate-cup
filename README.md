# Alternate Cup

Explore alternate FIFA World Cup timelines generated by AI. Ask "what if?" — get a full tournament history, awards, fan reactions, and a lasting legacy written by a football historian that never existed.

Built with Next.js 15, Supabase, Prisma, and OpenRouter (DeepSeek).

## Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 15 App Router |
| Language | TypeScript |
| Styling | Tailwind CSS v4 |
| Database | Supabase Postgres |
| ORM | Prisma |
| AI | OpenRouter → DeepSeek |
| Hosting | Vercel |

## Setup

### 1. Clone and install

```bash
git clone https://github.com/YOUR_USERNAME/alternate-cup.git
cd alternate-cup
npm install
```

### 2. Create a Supabase project

Go to [supabase.com](https://supabase.com), create a new project, then from **Project → Settings → Database** copy:
- **Transaction pooler** connection string → `DATABASE_URL`
- **Direct connection** string → `DIRECT_URL`

### 3. Get an OpenRouter key

Sign up at [openrouter.ai](https://openrouter.ai) and create an API key. The default model is `deepseek/deepseek-chat` — fast and cheap.

### 4. Configure environment

```bash
cp .env.example .env.local
```

Fill in `.env.local`:

```bash
DATABASE_URL="postgresql://postgres.PROJECT_REF:PASSWORD@REGION.pooler.supabase.com:6543/postgres?pgbouncer=true&connection_limit=1"
DIRECT_URL="postgresql://postgres.PROJECT_REF:PASSWORD@REGION.pooler.supabase.com:5432/postgres"
OPENROUTER_API_KEY="sk-or-..."
OPENROUTER_MODEL="deepseek/deepseek-chat"
OPENROUTER_SITE_URL="http://localhost:3000"
OPENROUTER_SITE_NAME="Alternate Cup"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
TRUSTED_CLIENT_IP_HEADER=""
```

`TRUSTED_CLIENT_IP_HEADER` — leave empty unless you're behind a reverse proxy that injects a trusted IP header (e.g. `CF-Connecting-IP` on Cloudflare). When empty, rate limiting falls back to a global fingerprint.

### 5. Run migrations and seed

```bash
npx prisma generate
npx prisma migrate deploy
npm run db:seed
```

### 6. Start dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push to GitHub
2. Import at [vercel.com/new](https://vercel.com/new)
3. Add all env vars from `.env.example` in the Vercel dashboard
4. Set `NEXT_PUBLIC_APP_URL` and `OPENROUTER_SITE_URL` to your production domain

Prisma migrations run via `npx prisma migrate deploy` — add this as a build command prefix or run it from CI before deploying.

## Project Structure

```
actions/          # Next.js Server Actions
app/              # App Router pages and API routes
  api/            # REST endpoints (views, shares)
  create/         # Universe creation page
  trending/       # Trending universes feed
  universe/[slug] # Universe detail page
components/       # React components
lib/
  ai/             # OpenRouter client, prompt builder, output schema
  db/             # Prisma client, repositories
  ranking/        # Trending and divergence scoring
  security/       # Rate limiting, request fingerprinting
  universes/      # Universe creation orchestration
prisma/
  schema.prisma   # Database schema
  seed.ts         # Example universes
```
